# NeuroGraphis

Neural network visualization and graph analysis tool for exploring deep learning model architectures, data flows, and layer-wise activations.

## Features

- Interactive model architecture visualization
- Layer-wise activation and gradient heatmaps
- Computational graph rendering
- Model comparison side-by-side
- Export visualizations as SVG and PNG

## Tech Stack

Python, PyTorch, Matplotlib, NetworkX, Graphviz

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/karthik-idikuda/NeuroGraphis.git
cd NeuroGraphis
pip install -r requirements.txt
```

### Usage

```bash
python visualize.py --model model.pth
```
